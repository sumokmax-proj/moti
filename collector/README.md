# 수집기 — 보관 중

> **2026-10-16 부터 보관만 한다.** 앱이나 데이터 형식이 바뀌어도 이 폴더는 더 맞추지 않는다. 지우지 않은 것은 나중에 다시 쓸 생각이 들 때를 위해서다.

## 왜 보관하는가

- 명언은 Claude 와 대화하며 모으는 쪽이 낫다. 대화에서는 원문을 직접 열어 대조하고(`npm run verify:sources`), 맥락과 번역을 함께 다듬는다. 수집기는 붙여넣은 내용의 모양만 검사할 수 있고, 출처가 진짜인지는 확인하지 못한다.
- 마지막 승인은 2026-10-09(id 136)이다. 그 뒤 137~177 은 모두 대화로 실었다.
- 데이터 형식이 바뀔 때마다 화면·서버·검증을 함께 맞춰야 했다(2026-10-15 하루에만 약 200줄). 쓰지 않는 도구를 맞추느라 앱 작업이 늘어났다.

## 보관한 시점의 상태

- 2026-10-15 의 데이터 형식까지는 맞춰 두었다: `source: { ko, en }`, `kind`, `circa`, `cited`, 승인하면 판권의 펴낸 날(`EDITION.date`)을 그날로 바꾸기.
- 그 뒤의 형식 변경은 반영되지 않는다. 다시 쓰기 전에 `quotes.js` 의 현재 모양과 맞는지부터 확인한다.
- 기계 규칙(길이 상한·태그·저자당 상한·출처 종류)의 기준은 이제 `tools/rules.js` 다. `server.js` 에 남은 값은 옮기던 때의 사본이라, 되살린다면 `tools/rules.js` 를 읽게 바꾸는 것이 먼저다.
- 승인 기록 71건(`data/pending-quotes.json`)도 그대로 둔다.
- GitHub Pages 에는 그대로 올라가 있다(…/moti/collector/). 앱에서 들어가는 길은 없다 — 로고의 숨은 입구는 2026-10-15 에 없앴다.

## 나중에 생각해 볼 것

- **회원별 「나만의 명언」** — 백엔드(회원·저장소)가 생기면, 수집기를 운영자 도구가 아니라 사람마다 자기 명언을 더하는 기능으로 바꿔 볼 수 있다. 백엔드부터 만들어야 해서 큰 작업이다.
- **베트남어 검수** — 검수자가 생기면 한 편씩 보고 `reviewed: true` 로 바꾸는 화면이 필요할 수 있다. 이 수집기는 「등록」용이라, 그때는 검수에 맞는 작은 화면을 새로 만드는 편이 나을 수 있다.

`collector/` 에 있다. 저장 위치가 두 가지고, 열 때 백엔드를 찾아보고 스스로 정한다. 어느 쪽인지는 화면 맨 위에 늘 표시된다.

### 백엔드 모드 — 등재까지 하려면 이쪽

```
npm run collector      # http://127.0.0.1:3001/collector/
```

- 검증 대기 목록은 `collector/data/pending-quotes.json` 에 저장된다.
- **승인하면 서버가 `quotes.js` 에 직접 등재한다.** id 는 파일 상단 `// 다음 id: N` 주석에서 받아 쓰고 주석을 하나 올린다.
- 등재 후 변경분을 확인하고 커밋하는 것은 사람이 한다.

로컬 전용 도구다. 인증이 없어서 `127.0.0.1` 에만 바인딩한다. 공개된 곳에 띄우지 말 것.

### 정적 모드 — GitHub Pages 등

백엔드가 없으면 브라우저 `localStorage` 에만 쌓인다. 승인해도 `quotes.js` 는 바뀌지 않는다. 대신 각 항목의 **코드 복사**와 승인 목록의 **전체를 quotes.js 코드로 복사**로 붙여넣을 코드를 얻는다.

### 넣는 방법 두 가지

- **폼** — 한 편씩 입력한다.
- **JSON 일괄 등록** — 배열이나 단일 객체를 붙여넣는다. 통과한 것만 들어가고, 걸린 항목은 몇 번째가 왜 걸렸는지 알려준다.

```json
[
  {
    "text": { "ko": "…", "en": "…" },
    "author": { "ko": "…", "en": "…" },
    "original": "…",
    "lang": "en",
    "source": "…",
    "year": 1758,
    "sourceUrl": "https://…",
    "tags": ["challenge"],
    "translator": "James Legge",
    "translatorUrl": "https://…"
  }
]
```

`translator` 는 공개된 정본 영역을 쓴 경우에만 적는다. 적었으면 `translatorUrl` 이 반드시 있어야 한다. 없으면 자체 번역으로 기록된다.

검사는 화면과 서버 양쪽에서 똑같이 한다 — 필수 항목, 길이 상한, `sourceUrl` 이 http(s) 인지, 태그가 아는 값인지, 같은 한국어 명언이 이미 있는지.
