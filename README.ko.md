# moti

명언 앱 **motimoti** 와 명언을 등재하는 **수집기**.

모든 명언은 1차 출처까지 확인한 것만 싣는다. "~라고 전해진다" 나 명언 사이트에서 옮겨온 것은 넣지 않는다.

- **수집기** — https://sumokmax-proj.github.io/moti/collector/ (읽기·시험용. 등재는 [수집기](#수집기) 참고)

## 기능

**읽기**

- 한 번에 한 편을 무작위로 펼친다. 「다음」 을 누르면 교차 페이드로 넘어간다.
- **최근 본 것 피하기** — 전체의 20%(100편이면 20편)는 다시 뽑지 않는다. 이 목록은 **앱을 닫아도 남아서**, 어제 마지막으로 본 명언이 오늘 첫 명언으로 나오지 않는다.
- **주르륵 넘김** — 「다음」 을 400ms 길게 누르거나 명언을 왼쪽으로 밀면 종이 4~7장이 엄지로 책장 넘기듯 지나간다. 빨라졌다가 800ms 에 걸쳐 잦아든다. 넘어가는 중에 아무 데나 누르면 그 자리에 멈춘다. 키보드는 `Shift` + `→`.
- **한 장 되돌리기** — 오른쪽으로 밀면(또는 `←`) 앞 장이 책등에서 다시 펴진다. **딱 한 장** 이고, 새로고침해도 된다. 더 없으면 쪽이 22px 들렸다가 살짝 넘겨 돌아오는 반동으로 끝을 알린다.
- **자동 크기 맞춤** — 작은 화면에서는 본문을 1px 씩 줄여 한 화면에 맞춘다(15px 까지). 글자 수를 세는 게 아니라 실제로 넘치는지를 재서 줄인다.

**담아두기**

- **즐겨찾기** — 명언마다 하트가 있고, 즐겨찾기 화면에서 편수와 함께 목록으로 본다. id 로 저장하므로 나중에 문구를 고치거나 언어를 바꿔도 따라온다.
- **자주 보기** — 즐겨찾기 화면 머리의 토글. 기본은 켜짐이고, 켜면 즐겨찾은 명언이 2배 자주 나온다. 최근 본 것을 거른 **다음에** 가중치가 붙으므로, 즐겨찾기라도 연달아 나오지는 않는다.
- **공유** — `navigator.share` 를 지원하면 그걸 쓰고, 아니면 클립보드에 복사하고 토스트를 띄운다.

**두 언어**

- 머리의 EN / KO 토글. 브라우저 언어는 한 번 직접 고르기 전까지만 참고하고, 고른 뒤에는 그 선택을 따른다.
- 모든 명언이 `ko` 와 `en` 을 둘 다 갖는다. 토글은 명언 본문·저자명·화면 문구를 한꺼번에 바꾼다.

**그 밖에**

- `prefers-color-scheme` 다크 모드, `prefers-reduced-motion` 이면 주르륵 넘김이 평범한 페이드가 된다.
- 키보드: `←` 되돌리기, `→` 다음, `Shift`+`→` 주르륵.
- 하트나 공유 버튼에서 시작한 밀기, 화면 가장자리 24px 안에서 시작한 밀기는 무시한다. 브라우저 자체 뒤로가기 제스처와 부딪히지 않게 하려는 것이다.
- **motimoti** 로고가 수집기로 가는 링크다(따로 알리지는 않는다).

## 명언과 출처

**100편**, id 3~136, 원문 언어 11종 — 영어 54, 한문 18, 라틴어 9, 독일어 4, 고대 그리스어 4, 한국어 4, 프랑스어 3, 스페인어·이탈리아어·네덜란드어·중국어 각 1.

기준 전문은 [QUOTE_STANDARDS.md](QUOTE_STANDARDS.md). 요약하면 근거가 **구체적이고**(작품과 위치 — 쪽·날짜·장·편지 번호 — 를 댈 수 있어야 한다), **그 시대의 것이고**(본인의 글, 받아적은 연설·인터뷰, 직접 목격자), **이미 가짜로 판정되지 않은** 것이어야 한다. 출처 외에 맥락 없이 혼자 읽혀야 하고(자립성), 읽는 사람에게 나아갈 길을 남겨야 한다(발전성). 저자당 최대 3편.

### 데이터 모양

`quotes.js` 는 평범한 배열이다. 한 항목은 이렇다.

```js
{
  id: 4,
  text:   { ko: "천 리 길도 발밑 한 걸음에서 시작된다.",
            en: "The journey of a thousand li commenced with a single step." },
  author: { ko: "노자", en: "Laozi" },
  translator: { en: "James Legge",                    // 공개된 정본 번역을 쓴 경우만
                enUrl: "https://www.gutenberg.org/cache/epub/216/pg216.txt" },
  original: "千里之行，始於足下",
  lang: "lzh",
  source: "『도덕경』 제64장 (왕필본)",
  year: -400,                                          // 음수는 기원전
  sourceUrl: "https://zh.wikisource.org/...",
  tags: ["challenge", "energy"],
}
```

| 항목 | 설명 |
|---|---|
| `id` | **재사용하지 않는다.** 즐겨찾기가 id 로만 맞추므로, 번호를 돌려쓰면 저장해둔 사람에게 엉뚱한 명언이 조용히 바뀌어 보인다. 삭제한 id 는 머리 주석에 적혀 있고, 새 번호는 거기 `// 다음 id: N` 에서 받는다. 최대 id 에서 세지 않는다. |
| `text`, `author` | `ko` 와 `en` 이 둘 다 있어야 한다. `text.ko` 는 `original` 에서 번역하며, 주장을 바꾸는 의역은 하지 않는다. |
| `original` | 원문 언어 그대로. 재검증 때 이것과 대조한다. |
| `translator` | `text.en` 이 공개된 정본 번역일 **때만** 적고, 그러면 `enUrl` 이 반드시 있어야 한다. 없으면 자체 번역이라는 뜻이다 — 빠뜨린 게 아니라 규칙이다. |
| `tags` | 1~3개: `despair` `failure` `challenge` `fear` `energy` `hope` `meaning` `perseverance` `freedom` `passion` `success` `preparation` `oriental`. (`failure_acceptance`, `dream`, `warning` 은 옛 태그라 받기는 하되 새로 쓰지 않는다.) |

### 길이 — 상한과 편집 원칙은 다른 것이다

**상한(한국어 100자 / 영어 200자)은 화면이 감당하는 최대치다.** 지원하는 가장 작은 기기(375×667)에서 재서 정했고, 품질과는 무관하다. 더 작은 320×568 에서는 `app.js` 의 `fitQuoteText` 가 본문을 한 눈금씩 줄여 맞춘다 — 그래서 상한만 지키면 화면이 깨지지 않는다. 15px 까지 줄여도 넘치면 거기서 멈추고 스크롤을 허용한다.

**엄선은 [QUOTE_STANDARDS.md](QUOTE_STANDARDS.md) 의 편집 원칙이 한다** — 한국어 40자 안쪽이 기본이고, 넘길 때는 이유가 있어야 한다. 숫자 하나가 두 일을 다 하려 들면 둘 다 어설퍼진다.

## 실행

빌드가 없다. `index.html` 을 열면 그대로 돈다.

```bash
# 실제 origin 이 필요하면
python3 -m http.server 8000
```

외부 의존은 Google Fonts 의 Hahmlet 하나뿐이고, 없으면 나눔명조·serif 로 떨어진다. 오프라인에서도 전부 동작한다.

## 수집기

`collector/` 에 있다. 저장 위치가 두 가지고, 열 때 백엔드를 찾아보고 스스로 정한다. 어느 쪽인지는 화면 맨 위에 늘 표시된다.

### 백엔드 모드 — 등재까지 하려면 이쪽

```bash
npm install          # 처음 한 번
npm run collector    # http://127.0.0.1:3001/collector/
```

- 검증 대기 목록은 `collector/data/pending-quotes.json` 에 저장된다.
- **승인하면 서버가 `quotes.js` 에 직접 등재한다.** id 는 파일 상단 `// 다음 id: N` 주석에서 받아 쓰고 주석을 하나 올린다. 임시 파일에 쓰고 바꿔치는 식이라 중간에 끊겨도 파일이 깨지지 않는다.
- 등재 후 변경분을 확인하고 커밋하는 것은 사람이 한다.

> 인증이 없는 로컬 전용 도구다. 그래서 `127.0.0.1` 에만 바인딩한다. 공개된 곳에 띄우지 말 것.

### 정적 모드 — GitHub Pages 등

백엔드가 없으면 브라우저 `localStorage` 에만 쌓인다. 승인해도 `quotes.js` 는 바뀌지 않는다. 대신 각 항목의 **코드 복사** 와 승인 목록의 **전체를 quotes.js 코드로 복사** 로 붙여넣을 코드를 얻는다.

### 넣는 방법 두 가지

- **폼** — 한 편씩 입력한다.
- **JSON 일괄 등록** — 배열이나 단일 객체를 붙여넣는다. 통과한 것만 들어가고, 걸린 항목은 몇 번째가 왜 걸렸는지 알려준다.

```json
[
  {
    "text": { "ko": "…", "en": "…" },
    "author": { "ko": "…", "en": "…" },
    "original": "…",
    "lang": "en",
    "source": "…",
    "year": 1758,
    "sourceUrl": "https://…",
    "tags": ["challenge"],
    "translator": "James Legge",
    "translatorUrl": "https://…"
  }
]
```

`translator` 는 공개된 정본 번역을 쓴 경우에만 적는다. 적었으면 `translatorUrl` 이 반드시 있어야 한다. 없으면 자체 번역으로 기록된다. (입력할 때는 이렇게 두 개의 문자열이고, 저장될 때 `translator: { en, enUrl }` 이 된다.)

검사는 화면과 서버 양쪽에서 똑같이 한다 — 필수 항목, 길이 상한, `sourceUrl` 이 http(s) 인지, 태그가 아는 값인지, 같은 한국어 명언이 이미 있는지.

## 점검 도구 — `tools/`

명언을 넣거나 고친 뒤, 커밋하기 전에 돌린다. 기준값(길이 상한, 태그, 저자당 상한)은 `collector/server.js` 에서 읽으므로 따로 맞출 것이 없다.

| 명령 | 하는 일 | 걸리는 시간 |
|---|---|---|
| `npm run check` | 데이터 점검 — id 중복·삭제 id 재사용·「다음 id」, 필수 필드·길이·태그, 저자당 상한, 머리 주석의 번역 경로 개수·목록, 수집기 승인 기록 | 1초, 네트워크 없음 |
| `npm run verify:sources` | 출처 원문 대조 — 기록된 `sourceUrl` 을 실제로 열어 `original` 이 있는지, `translator.enUrl` 에 `text.en` 이 있는지 본다. `-- --ids 59,63` · `-- --from 124` 로 좁힐 수 있다 | 전체 10초 남짓 |
| `npm run test:app` | 앱 동작 — 화면 그리기(390×844·320×568), 최근 20% 피하기, 주르륵 넘김, 뒤로 가기·반동, 즐겨찾기가 고친 문구를 따라가는지, 더 자주 펼치기, 페이지 오류 | 30초 남짓 |
| `npm test` | `check` + `test:app` | |

`test:app` 은 Playwright 를 쓴다. 처음 한 번 `npm install` 이 필요하다(전역에 깔려 있으면 `NODE_PATH=$(npm root -g)` 로도 된다). 하나라도 실패하면 종료 코드 1.

## 파일 구조

```
index.html          앱 마크업 — 한 페이지, 두 화면
app.js              앱 동작 전부: 명언, 제스처, 즐겨찾기, 언어, 크기 맞춤
quotes.js           명언 100편 + 머리 주석의 수록 규칙
style.css           레이아웃과 컴포넌트
tokens.css          색·타이포·간격 토큰 — 수집기도 같은 파일을 쓴다
QUOTE_STANDARDS.md  무엇을 실을 수 있는가, 그리고 왜
collector/          명언 수집·검토 (정적 / 백엔드 모드)
tools/              check-data · verify-sources · test-app
.design/            디자인 아트보드 (확정 5화면 + 시안 A~G)
docs/               이 문서가 쓰는 스크린샷
```

브라우저 저장소는 전부 `localStorage` 다.

| 키 | 담는 것 |
|---|---|
| `motimoti-favorites` | 즐겨찾기 — id 와 대비용 text/author 스냅샷 |
| `motimoti-lang` | `"en"` 또는 `"ko"`. 값이 있으면 브라우저 언어 감지를 하지 않는다 |
| `motimoti-recent` | 최근 본 id, 전체의 20%까지. 「한 장 되돌리기」의 근거이기도 하다 |
| `motimoti-favorites-weight` | 「자주 보기」의 `"on"` / `"off"` |

## 배포

`main` 에 푸시하면 GitHub Pages 가 자동으로 배포한다. 별도 워크플로 파일은 없고 Pages 기본 빌드를 쓴다.

### css/js 를 고쳤으면 `?v=` 를 올린다

`index.html` 과 `collector/index.html` 이 로컬 css/js 를 `?v=날짜` 로 불러온다(지금은 `20261011b`). Pages 가 이 파일들을 10분간 캐시하기 때문에, 값을 올리지 않으면 돌아온 사람의 브라우저가 **새 HTML 과 옛 js 를 섞어 쓴다.** 실제로 한 번 겪었다 — 「전체 명언」 탭이 배지 0, 빈 목록, 오류 메시지도 없이 조용히 비어 있었다.

두 파일의 `?v=` 를 같은 값으로 올리면 URL 이 바뀌어 캐시가 무효가 된다. **`quotes.js` 에도 붙어 있으므로 명언을 등재한 뒤에도 올려야 한다.** 안 올리면 새 명언이 최대 10분간 안 보인다.

## 디자인

`.design/` 에 확정안 5화면과 시안 A~G 가 각각 독립 아트보드로 들어 있고, `canvas.json` 이 배치와 판단 근거를 갖고 있다. 빌드에 쓰이지는 않는 참고 자료이고, 확정안(E)은 `tokens.css` 와 `style.css` 에 들어가 있다. 색은 WCAG AA 로 맞췄다 — 테라코타 `#B4593A` 는 3.97:1 이라 그래픽에만 쓰고, 글자와 테두리는 5.3:1 인 `#9C4529` 를 쓴다.
